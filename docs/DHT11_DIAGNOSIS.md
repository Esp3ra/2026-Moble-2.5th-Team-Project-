# DHT11 온도 급변 점검 — 2026-10-15

## 현재 판단

원인은 아직 확정하지 않았다. 과거 로그에서는 운전 중 26.4 → 30.2 → 27.1 → 29.6°C의 변화가 있었고, 긴급 정지 뒤에는 값이 안정됐다. 다만 사용자가 가열 후 팬을 가까이 대어 식힌 시험도 했다고 설명했으므로, 과거 구간을 일정한 온도에서의 전기 부하 비교로 취급하면 안 된다.

- 사용자 확인: DHT11은 Mega 5V 센서 전원 레일에 연결됨. MQ-9과 떨어뜨린 뒤에도 급변 경험.
- 추가 사용자 확인: 식히는 데 사용한 팬은 Jetson에 연결되어 있다. 정확한 포트와 팬 종류는 확인되지 않았다. Mega도 Jetson USB에서 전원을 받는 구성이라 전원 영향은 비교 대상이지만, 이 사실만으로 전압 강하나 잡음을 확정할 수 없다. Jetson 냉각용 팬이라면 중지하지 않고 센서 위치를 바꾸어 열·바람 영향을 분리한다.
- 센서 읽기: 2.5초 간격, Adafruit DHT 1.4.6의 펄스 시간 제한 및 체크섬 검사 사용. 온도와 습도는 같은 측정 패킷을 사용한다.
- 측정 온도에 보정 오프셋이나 평활화를 추가하지 않는다. 정책 버전 6에서는 사용자 요청에 따라 28°C 위험 시 D10 정지·D9 0°·빨강 유지·부저 꺼짐을 적용하며, 27°C 미만이 5초 이상 유지되면 자동 복귀한다. 이 제어 변경은 센서 급변 원인의 해결과 구분한다.
- 전압·접지 잡음은 계측하지 않았다. 전원 문제나 센서 고장으로 단정할 수 없다.

## LED·부저 분리 시험 결과

`scripts/dht_load_check.py --run-indicators`로 각 단계 18초씩 비교했다. 처음 6초를 제외한 온도 범위는 다음과 같다.

| 단계 | 온도 범위 |
|---|---|
| 긴급 정지 기준 | 25.9–26.1°C |
| LED만 켜기 | 25.8–25.9°C |
| LED와 기존 저음량 부저 켜기 | 25.4–25.7°C |
| 다시 긴급 정지 | 25.3–25.5°C |

D9는 0° 닫힘 위치로 유지했고 D10은 계속 정지했다. 센서 오류, 명령 ACK 불일치, 시리얼 프레임 오류는 없었다. 이 조건에서 급변은 재현되지 않았다. 카메라·GPU 프로그램을 일시 중지한 시험이므로 전체 운전 중 전원 영향을 배제하지는 못한다. 별도 팬이나 열 자극이 시험 내내 없었는지는 원격으로 확인하지 못했다.

결과의 `samples`는 수신한 텔레메트리 패킷 수다. 텔레메트리는 약 0.5초마다 오지만 DHT11 측정은 2.5초마다 하므로, 모두 독립적인 센서 측정값은 아니다.

시험 후 관리자 프로그램을 `--start-stopped`로 재실행했다. 실제 상태는 `logs/status.json`에서 확인한다. 진단 스크립트는 관리자 프로그램을 정상 종료하고 시리얼 포트를 해제한 상태에서만 실행한다.

관리자 화면 복구 뒤 관찰에서는 운전이 재개됐으며 25.1–30.6°C, 습도 48–58%가 기록됐다. 열·바람 자극을 통제하지 않았으므로 이 구간도 원인 확정에 사용하지 않는다. 이후 센서 데이터는 유효하지만 `hardware_ready=false`인 오류가 발생했다. 변경하지 않은 펌웨어에서 이 값에 영향을 주는 가변 조건은 `lcdReady`이므로 LCD I2C 타임아웃으로 해석했다. 오류로 모터가 정지한 뒤 기존 프로그램을 정지 상태로 재실행하여 센서·LCD 준비 상태와 카메라가 복구되는 것을 확인했다. 16:19:46 마지막 확인에서는 운전이 재개된 상태였으며 센서·하드웨어 준비 정상, 오류 없음이었다. 이 복구가 배선이나 전원 문제의 해결을 뜻하지는 않는다.

## 다음 비교 조건

16:22:25까지의 최근 60초 로그에서는 26.8→25.5°C로 내려왔으며, 연속 기록 사이 최대 변화는 0.3°C, 장치 오류는 없었다. 직전 120초 전체에는 최대 2.8°C 변화도 남아 있으므로 해결 완료로 판정하지 않는다.

1. 열원과 MQ-9에서 떨어진 위치에 DHT11과 배선을 고정하고 손·입김·가열·추가 팬의 영향을 제거한다. 먼저 온도가 안정되는지 기록한다.
2. 같은 위치와 조건에서 정지와 운전을 비교한다. 식히는 데 사용한 팬은 Jetson 연결로 확인됐으며, 정확한 연결 포트와 냉각팬 여부는 추가로 확인한다.
3. 급변이 운전 때만 재현되면 센서 전원·공통 접지 배선과 실제 센서 단자 전압을 확인한다. 전원을 끈 상태에서 배선 접촉을 점검한다. 서보 전류가 센서 접지 배선을 경유하지 않도록 한다.
4. 전원과 배선을 확인한 뒤에도 재현되면 다른 온도계와 비교하거나 DHT11을 교체해 구분한다. 실제 변화인지 판단하기 전에 급변값을 임의로 버리거나 낮추지 않는다.
