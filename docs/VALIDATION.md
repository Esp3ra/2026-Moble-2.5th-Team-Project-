## 실제 소프트웨어 연동 및 창 입력 복구

Mega에는 `mega_controller`의 bench 펌웨어를 업로드했습니다. 실제 DHT11·MQ-9 원시값·LCD·카메라/GPU와 운영 화면을 연결했고, 사용자 PIN 최초 설정과 인원 승인 실행을 확인했습니다. 초기 화면은 키보드는 동작하지만 마우스 클릭이 전달되지 않았습니다. Unity/Compiz 창 관리자를 재시작한 뒤 사용자가 정상 클릭을 확인했으며 PIN은 유지됐습니다.

초기 연동에서는 약 50초마다 ACK 시간 초과가 반복됐습니다. DHT 읽기에 더해 LCD 갱신도 센서 보고 전에 끝내도록 바꿔, 호스트 명령이 들어올 때 MCU가 긴 주변장치 작업을 하지 않도록 수정했습니다. 이후 첫 120초 관찰에서는 재연결은 없었으나 거부 패킷 5개와 일시적인 MCU 통신 경보가 있었습니다. 해당 한 차례의 직접 원인은 확정하지 못했으며 기록을 `artifacts/integration-live-before-final-check.json`에 보존했습니다. 패킷 거부 사유 로그도 추가했습니다.
